# One Emoji, One Dream Vacation

Entry for the [One Emoji, One Dream Vacation](https://make.fun/c/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) competition on [make.fun](https://make.fun).

The program writes exactly one emoji to `/output/entry.txt`: **🗻 Mount Fuji**.

Why Mount Fuji, against the judge's brief:

1. **Exactly one emoji, no words, and it lands on a dream vacation.** The
   judge's brief names "a mountain" and "a faraway place" as dream-vacation
   markers — Mount Fuji is both at once.
2. **A vivid postcard at a glance.** Snow-capped Fuji is one of the most
   photographed views on earth; a stranger sees the place before reading a
   word.
3. **Personal and specific, not generic.** A particular dream — Japan, Fuji —
   rather than any holiday.
4. **A spark of wit and surprise.** A fresh pick beside the beach cliche.
5. **Reads instantly across cultures and screens.** Fuji is iconic worldwide.

## Run

```sh
node main.ts
```

This writes the single emoji (no trailing newline) to `/output/entry.txt`.
